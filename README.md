# QuizOS (MVP)

Live pubquiz engine (Kahoot-alternative) built with Next.js for Vercel.

## Quickstart

1) Install deps
```bash
npm install
```

2) Add `.env.local` (see `.env.example`)

3) Run
```bash
npm run dev
```

## Deploy (Vercel)

- Import repo in Vercel
- Add environment variables
- Deploy
